# DB에 영속화한 AI Job을 기동·주기적 스캔으로 실행

분석과 임베딩의 논리적 실행을 공통 AiRequestJob에 기록하고, 신규 Guide와 임베딩 Job은 같은 트랜잭션에 저장한다. 메시지 브로커는 도입하지 않으며, 후속 요청에만 복구를 맡기면 새 요청이 없을 때 작업이 남을 수 있으므로 기동 직후와 주기적 DB 스캔으로 실행·복구하기로 결정했다. 호출자의 대기·연결 수명은 Job 수명과 분리하고, 소유권·lease·실행 버전으로 DB 변경을 보호한다.

외부 호출의 정확히 한 번 실행과 엄격한 전역 호출 상한은 보장하지 않는다. 임베딩은 Guide ID upsert와 실제 저장 완료 응답을 필수 계약으로 요구한다. 실행·재시도·타임아웃의 상세 정책은 [구현 계획 5~7절](../youtube-analysis-refactoring-plan.md#5-공통-실행재시도복구)을 따른다.
