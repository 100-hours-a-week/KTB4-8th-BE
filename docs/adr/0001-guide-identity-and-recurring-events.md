# Guide 동일성과 반복 행사 모델 유지

Guide는 유형·이름·도로명주소의 정확한 원문 조합으로 식별하고, 같은 키가 이미 있으면 기존 필드를 보존한다. 행사와 회차를 분리하는 대안을 검토했으나 이번 리팩토링에서는 기존 행사 모델을 유지하기로 결정했다. 따라서 반복 행사에 과거 기간이 남아 새 회차의 이용 가능성 판단에서 제외될 수 있으며, 회차별 최신 정보 제공을 위해 기존 기간을 자동 갱신하지 않는다.

이 결정은 대표 Guide와 참조 데이터의 동일성을 고정하므로 변경 시 데이터 및 외부 벡터 식별자 이관이 필요하다. 상세 정책과 이관 절차는 [#248](https://github.com/100-hours-a-week/KTB4-8th-BE/issues/248)을 따른다.
